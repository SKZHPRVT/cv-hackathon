1.1. ЧТО ОБЫЧНО ДАЮТ НА ХАКАТОНЕ
----------------------------------

Типы заданий:
- Классификация изображений (бинарная/мультиклассовая)
- Детекция объектов (найти и отметить объекты)
- Сегментация (выделить области)
- Подсчет объектов (count)
- Сравнение изображений
- Генерация/улучшение изображений

Данные:
- Размер датасета: от 100 до 10000+ изображений
- Форматы: JPG, PNG, BMP
- Размеры: от 32x32 до 4K
- Разметка: CSV, JSON, папки по классам

Ограничения:
- Время: обычно 24-48 часов
- Ресурсы: ограниченный доступ к GPU
- Интернет: может быть ограничен
- Команда: 3-5 человек

1.2. ЧТО ОЦЕНИВАЮТ
-------------------

Критерии оценки:
1. Точность решения (метрики)
2. Скорость работы
3. Оригинальность подхода
4. Качество презентации
5. Практическая применимость
6. Масштабируемость

Метрики:
- Accuracy (точность)
- F1-score
- Precision/Recall
- IoU (для сегментации)
- mAP (для детекции)
- Время инференса

ЧАСТЬ 2: ПОДВОДНЫЕ КАМНИ И ТРУДНОСТИ
================================================================================

2.1. ДАННЫЕ
------------

Проблема: Дисбаланс классов
Решение:
- Взвешенный loss (class weights)
- Oversampling меньшинства
- Аугментации для меньшинства
- Focal Loss

Проблема: Мало данных
Решение:
- Transfer learning (предобученные модели)
- Сильные аугментации
- Генерация синтетических данных
- Few-shot learning

Проблема: Шумные данные
Решение:
- Очистка данных
- Robust loss (MAE вместо MSE)
- Фильтрация выбросов

Проблема: Разные размеры изображений
Решение:
- Resize до общего размера
- Адаптивный pooling
- Сохранение аспектного соотношения

2.2. МОДЕЛЬ
------------

Проблема: Overfitting
Симптомы: train accuracy >> val accuracy
Решение:
- Больше аугментаций
- Dropout
- Weight decay
- Early stopping
- Меньше модель

Проблема: Underfitting
Симптомы: обе метрики низкие
Решение:
- Больше эпох
- Сложнее модель
- Меньше learning rate
- Лучше предобработка

Проблема: Долгое обучение
Решение:
- Mixed precision
- Меньше image_size
- Больше batch_size
- Заморозка слоев

2.3. GPU
---------

Проблема: CUDA out of memory
Решение:
- Уменьшить batch_size
- Уменьшить image_size
- Использовать gradient accumulation
- Меньше модель

Проблема: Нет GPU
Решение:
- Использовать CPU с оптимизациями
- Меньше модель (MobileNet)
- ONNX ускорение
- Облачные сервисы

2.4. ВРЕМЯ
----------

Проблема: Не успеваем
Решение:
- Приоритизация задач
- Параллельная работа
- Использовать готовые решения
- Минимальный viable product

Проблема: Долгий инференс
Решение:
- ONNX конвертация
- Квантизация (INT8)
- Уменьшение модели
- Батч-обработка

2.5. КОМАНДА
------------

Проблема: Несогласованность
Решение:
- Четкое распределение ролей
- Регулярные встречи
- Общий репозиторий
- Документация

Проблема: Конфликты версий
Решение:
- requirements.txt
- Docker
- Виртуальные окружения
- Фиксированные версии
