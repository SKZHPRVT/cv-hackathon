================================================================================
                    ПОИСК ПОХОЖИХ ОБЪЕКТОВ (EMBEDDING SEARCH)
================================================================================

НАЗНАЧЕНИЕ
==========
Поиск похожих объектов на основе эмбеддингов (векторов признаков).
Использует предобученные модели для извлечения признаков из изображений.

ЗАДАЧИ КОТОРЫЕ РЕШАЕТ
======================
- Распознавание лиц (если есть база лиц)
- Поиск похожих товаров
- Re-identification (найти человека с другой камеры)
- Поиск дубликатов
- Рекомендательные системы

УСТАНОВКА

pip install torch timm albumentations opencv-python scikit-learn

================================================================================
РЕЖИМЫ РАБОТЫ
================================================================================

1. BUILD - создание базы эмбеддингов
2. SEARCH - поиск похожих изображений
3. COMPARE - сравнение двух изображений

================================================================================
1. СОЗДАНИЕ БАЗЫ ЭМБЕДДИНГОВ
================================================================================

Команда:
python embedding_search.py --mode build --input data/database_images/ --database embeddings.pkl

Параметры:
--input: папка с изображениями для базы
--database: файл для сохранения базы (по умолчанию embeddings.pkl)
--model: модель для эмбеддингов (по умолчанию resnet18)

Что происходит:
1. Загружает все изображения из папки
2. Извлекает эмбеддинги через предобученную модель
3. Сохраняет базу в pickle файл

Пример:
python embedding_search.py --mode build --input data/faces/ --database faces_db.pkl --model efficientnet_b0

================================================================================
2. ПОИСК ПОХОЖИХ ИЗОБРАЖЕНИЙ
================================================================================

Команда:
python embedding_search.py --mode search --query test.jpg --database embeddings.pkl --top_k 5

Параметры:
--query: изображение для поиска
--database: файл базы эмбеддингов
--top_k: количество результатов (по умолчанию 5)
--save_results: сохранить найденные изображения в папку

Что происходит:
1. Загружает базу эмбеддингов
2. Извлекает эмбеддинг из query-изображения
3. Считает косинусное сходство со всеми изображениями в базе
4. Выводит топ-K наиболее похожих

Пример с сохранением:
python embedding_search.py --mode search --query test.jpg --database embeddings.pkl --top_k 10 --save_results

================================================================================
3. СРАВНЕНИЕ ДВУХ ИЗОБРАЖЕНИЙ
================================================================================

Команда:
python embedding_search.py --mode compare --input image1.jpg --image2 image2.jpg

Параметры:
--input: первое изображение
--image2: второе изображение

Что происходит:
1. Извлекает эмбеддинги из обоих изображений
2. Считает косинусное сходство
3. Выводит процент схожести

Интерпретация результатов:
- 90-100%: очень похожи (возможно, одно и то же)
- 70-90%: похожи
- 50-70%: немного похожи
- 0-50%: не похожи

================================================================================
ДОСТУПНЫЕ МОДЕЛИ

python embedding_search.py --mode build --input data/ --model efficientnet_b0

================================================================================
ПРАКТИЧЕСКИЕ СЦЕНАРИИ
================================================================================

Сценарий 1: Поиск дубликатов
------------------------------
1. Создайте базу из всех изображений
2. Для каждого изображения найдите топ-1 совпадение
3. Если схожесть > 95%, это дубликат

Сценарий 2: Распознавание лиц
-------------------------------
1. Создайте базу из фотографий сотрудников
2. При появлении нового лица - найдите в базе
3. Если схожесть > 80%, это тот же человек

Сценарий 3: Поиск похожих товаров
-----------------------------------
1. Создайте базу из каталога товаров
2. Сфотографируйте товар
3. Найдите похожие в базе

Сценарий 4: Re-identification
-------------------------------
1. Создайте базу из кадров с камеры 1
2. Получите кадр с камеры 2
3. Найдите того же человека

================================================================================
СОВЕТЫ
================================================================================

1. Используйте более точные модели для сложных задач
2. Нормализуйте изображения перед созданием базы
3. Для больших баз используйте FAISS (если нужно ускорение)
4. Сохраняйте несколько баз для разных задач
5. Обновляйте базу при добавлении новых объектов

================================================================================
РЕШЕНИЕ ПРОБЛЕМ
================================================================================

Проблема: База слишком большая
Решение: Используйте resnet18 вместо efficientnet_b3

Проблема: Низкая точность поиска
Решение: 
- Используйте более точную модель
- Увеличьте размер изображений
- Добавьте больше изображений в базу

Проблема: Долгий поиск
Решение:
- Уменьшите размер базы
- Используйте более быструю модель
- Рассмотрите FAISS для больших баз
