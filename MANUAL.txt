3. ОПИСАНИЕ ФАЙЛОВ
================================================================================

3.1. configs/config.yaml
------------------------
Назначение: Конфигурация для классификации.

Параметры:
- data.train_path: путь к тренировочным данным
- data.val_path: путь к валидационным данным
- model.name: название модели (resnet18, efficientnet_b0 и др.)
- training.epochs: количество эпох
- training.batch_size: размер батча
- training.learning_rate: скорость обучения
- training.image_size: размер изображений
- training.early_stopping: остановка при отсутствии улучшений
- training.mixed_precision: ускорение на GPU

3.2. configs/yolo_data.yaml
---------------------------
Назначение: Конфигурация для YOLO.

Параметры:
- train: путь к тренировочным изображениям
- val: путь к валидационным изображениям
- test: путь к тестовым изображениям
- nc: количество классов
- names: список имен классов

3.3. train.py
-------------
Назначение: Обучение классификационной модели.

Аргументы:
--config: путь к конфигу
--model: модель (переопределяет конфиг)
--epochs: количество эпох
--batch_size: размер батча
--lr: learning rate
--fast: быстрый тест

3.4. yolo_train.py
------------------
Назначение: Обучение YOLO для детекции/сегментации.

Аргументы:
--mode: train, predict или export
--data: путь к data.yaml
--model: размер модели (n, s, m, l, x)
--source: путь к изображению для предсказания
--epochs: количество эпох
--imgsz: размер изображения
--task: detect, segment, classify, pose

3.5. predict.py
---------------
Назначение: Инференс классификационной модели.

Аргументы:
--checkpoint: путь к чекпоинту
--image: путь к изображению
--folder: путь к папке
--image_size: размер изображения

3.6. tta_predict.py
-------------------
Назначение: Инференс с Test Time Augmentation.

Аргументы:
--checkpoint: путь к чекпоинту
--image: путь к изображению
--image_size: размер изображения

3.7. export_onnx.py
-------------------
Назначение: Конвертация модели в ONNX.

Аргументы:
--checkpoint: путь к чекпоинту
--output: путь для сохранения
--image_size: размер изображения
--test: проверить ONNX после конвертации

3.8. app.py
-----------
Назначение: Веб-интерфейс.

Вкладки:
- Инференс: предсказание на изображениях
- Анализ данных: статистика датасета
- Разделение данных: подготовка данных
- Обучение: запуск обучения

================================================================================
4. ОПИСАНИЕ ФУНКЦИЙ
================================================================================

4.1. ImageDataset (utils/dataset.py)
-------------------------------------
Что делает: Загружает изображения из структуры папок.
Вход: root_path, transform, is_train
Выход: тензор изображения, метка класса

4.2. get_transforms (utils/dataset.py)
---------------------------------------
Что делает: Создает аугментации.
Вход: image_size, is_train
Выход: объект трансформаций

4.3. create_dataloaders (utils/dataset.py)
-------------------------------------------
Что делает: Создает DataLoader'ы.
Вход: train_path, val_path, batch_size, num_workers, image_size
Выход: train_loader, val_loader, class_names

4.4. calculate_metrics (utils/metrics.py)
------------------------------------------
Что делает: Считает метрики.
Вход: y_true, y_pred, num_classes
Выход: словарь с метриками

4.5. split_dataset (utils/split_data.py)
-----------------------------------------
Что делает: Разделяет данные.
Вход: source_path, train_ratio, val_ratio, test_ratio, seed
Выход: создает папки train/val/test

4.6. analyze_dataset (utils/check_data.py)
-------------------------------------------
Что делает: Анализирует датасет.
Вход: data_path
Выход: отчет о данных

4.7. train_yolo (yolo_train.py)
-------------------------------
Что делает: Обучает YOLO модель.
Вход: data_yaml, model_size, epochs, imgsz, task
Выход: результаты обучения

4.8. predict_with_tta (tta_predict.py)
---------------------------------------
Что делает: Предсказание с TTA.
Вход: model, image_path, class_names, device, image_size
Выход: предсказания

4.9. export_to_onnx (export_onnx.py)
-------------------------------------
Что делает: Конвертирует модель в ONNX.
Вход: checkpoint_path, output_path, image_size
Выход: ONNX файл

5. БЫСТРЫЙ СТАРТ (5 МИНУТ)

Шаг 1: Установка (2 минуты)
----------------------------
python3 -m venv venv
source venv/bin/activate

Шаг 2: Подготовка данных (1 минута)
------------------------------------
python utils/split_data.py --source data/all_data

---------------------------

# Детекция:
python yolo_train.py --mode train --data configs/yolo_data.yaml

Шаг 4: Инференс (1 минута)
---------------------------
python predict.py --checkpoint checkpoints/best_model.pth --image test.jpg

7. РЕШЕНИЕ ПРОБЛЕМ
================================================================================

Проблема: CUDA out of memory
Решение:
- python train.py --batch_size 16
- python train.py --model resnet18

Проблема: Медленное обучение
Решение:
- Уменьшите image_size в конфиге
- Увеличьте num_workers
- Включите mixed_precision

Проблема: Overfitting
Решение:
- Добавьте аугментации
- Увеличьте weight_decay
- Используйте early stopping

Проблема: Underfitting
Решение:
- Увеличьте epochs
- Уменьшите learning_rate
- Используйте более сложную модель

Проблема: Ошибка загрузки данных
Решение:
- Проверьте пути в config.yaml
- Убедитесь, что папки существуют
- Проверьте форматы файлов

Проблема: YOLO не запускается
Решение:
- pip install ultralytics
- Проверьте формат данных YAML
- Убедитесь, что изображения в правильных папках

Проблема: ONNX не работает
Решение:
- pip install onnxruntime
- Проверьте версию PyTorch
- Попробуйте opset_version=11

10. YOLO ДЕТЕКЦИЯ
================================================================================

Подготовка данных для YOLO:

Структура данных:
data/
├── train/
│   ├── images/
│   │   └── img1.jpg
│   └── labels/
│       └── img1.txt
├── val/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/

Формат labels (txt):
class_id x_center y_center width height

Пример:
0 0.5 0.5 0.3 0.4

Команды:
# Обучение детекции
python yolo_train.py --mode train --data configs/yolo_data.yaml --model n --epochs 50

# Обучение сегментации
python yolo_train.py --mode train --data configs/yolo_data.yaml --task segment

# Предсказание
python yolo_train.py --mode predict --model runs/detect/train/weights/best.pt --source test.jpg

# Экспорт в ONNX
python yolo_train.py --mode export --model runs/detect/train/weights/best.pt

================================================================================
11. ONNX И TTA
================================================================================

ONNX конвертация:
python export_onnx.py --checkpoint checkpoints/best_model.pth --output model.onnx --test

Преимущества ONNX:
- Быстрее инференс (2-3x)
- Меньше размер
- Кросс-платформенность
- Оптимизация под CPU/GPU

TTA предсказание:
python tta_predict.py --checkpoint checkpoints/best_model.pth --image test.jpg

TTA включает:
- Оригинал
- Horizontal Flip
- Vertical Flip
- Усреднение предсказаний

Преимущества TTA:
- +1-3% к точности
- Более стабильные предсказания
- Бесплатное улучшение
