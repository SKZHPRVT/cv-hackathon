1. ОБЩЕЕ ОПИСАНИЕ
================================================================================

CV Hackathon Toolkit Pro — готовый инструментарий для решения задач
компьютерного зрения на хакатонах.

ПОДДЕРЖИВАЕМЫЕ ЗАДАЧИ:
1. Классификация изображений (timm + Hugging Face)
2. Детекция объектов (YOLO)
3. Сегментация (YOLO-seg + SAM)
4. Поиск похожих объектов (Embedding Search)
5. Zero-shot классификация (CLIP)
6. Генерация изображений (Stable Diffusion)

КЛЮЧЕВЫЕ ОСОБЕННОСТИ:
- Воспроизводимость (seed для Python, NumPy, PyTorch, CUDA)
- Стратифицированное разделение данных
- Защита от пустых классов
- Гарантированное сохранение чекпоинта
- Единый препроцессинг (mean/std/image_size из чекпоинта)
- Поиск дубликатов и утечек
- Smoke test окружения
- Журнал экспериментов (JSON)
- CSV-разметка
- Генератор submission
- Offline-режим (кеширование моделей)
- HF кеширование в памяти
- ONNX с проверкой эквивалентности

3. ОПИСАНИЕ КАЖДОГО ФАЙЛА
================================================================================

3.1. configs/config.yaml
------------------------
Назначение: Конфигурация обучения.

Секции:
- data: пути к данным, CSV-разметка
- model: имя модели, pretrained
- training: epochs, batch_size, lr, image_size, early_stopping, mixed_precision
- augmentation: конфигурируемые аугментации (ВСЕ ВЫКЛЮЧЕНЫ по умолчанию)
- logging: save_dir, log_interval

Аугментации (включаются вручную):
- horizontal_flip: false
- vertical_flip: false
- random_rotate: false
- random_crop: false
- brightness_contrast: false
- hue_saturation: false
- coarse_dropout: false

3.2. utils/dataset.py
---------------------
Назначение: Датасеты и аугментации.

Классы:
- ImageDataset: датасет из структуры папок
- CSVImageDataset: датасет из CSV (path, label)

Функции:
- get_transforms(image_size, is_train, augmentation_config)
- create_dataloaders(...)

Константы:
- MEAN = [0.485, 0.456, 0.406] (ImageNet)
- STD = [0.229, 0.224, 0.225]
- DEFAULT_IMAGE_SIZE = 224

3.3. utils/metrics.py
---------------------
Назначение: Метрики.

Функции:
- calculate_metrics(y_true, y_pred, class_names) — число классов из class_names
- plot_confusion_matrix(...)
- plot_training_history(...)
- print_metrics(...)

3.4. utils/split_data.py
------------------------
Назначение: Стратифицированное разделение.

Параметры:
--source, --train_ratio, --val_ratio, --test_ratio, --seed, --min_val_per_class

Особенности:
- Защита от пустых классов
- Гарантия min_val_per_class изображений в val
- Нормализация ratios если сумма != 1

3.5. utils/check_data.py
------------------------
Назначение: Анализ датасета.

Проверяет:
- Количество изображений
- Баланс классов
- Размеры
- Битые файлы
- Форматы

3.6. utils/find_duplicates.py
-----------------------------
Назначение: Поиск дубликатов и утечек.

Режимы:
- --exact: точные дубликаты по MD5
- --near: почти дубликаты по pHash
- --leakage: утечки между train/val/test

3.7. train.py
-------------
Назначение: Обучение классификатора.

Аргументы:
--config, --model, --epochs, --batch_size, --lr, --seed, --fast, --exp_name

Функции:
- set_seed(seed)
- train_epoch(...)
- validate(...)
- save_checkpoint(...) — гарантированное сохранение
- log_experiment(...) — JSON журнал

3.8. yolo_train.py
------------------
Назначение: YOLO для детекции/сегментации.

Режимы:
--mode train: обучение
--mode predict: инференс
--mode export: ONNX

Параметры:
--data, --model (n/s/m/l/x), --epochs, --imgsz, --task (detect/segment/classify/pose)

3.9. predict.py
---------------
Назначение: Инференс.

Берет из чекпоинта:
- model_name
- class_names
- image_size
- mean/std

3.10. tta_predict.py
--------------------
Назначение: TTA предсказание.

Варианты:
- none: без TTA
- hflip: горизонтальный flip
- vflip: вертикальный flip
- all: hflip + vflip + rotate

3.11. export_onnx.py
--------------------
Назначение: Конвертация в ONNX.

Функции:
- export_to_onnx(...)
- test_equivalence(...) — сравнение PyTorch vs ONNX
- compare_speed(...) — замер скорости

3.12. embedding_search.py
-------------------------
Назначение: Поиск похожих объектов.

Режимы:
- build: создание базы эмбеддингов
- search: поиск похожих
- compare: сравнение двух изображений

3.13. hf_models.py
------------------
Назначение: Hugging Face модели.

Режимы:
- check: проверка установки
- list: список моделей
- dataset: информация о датасете
- classify: классификация
- zero_shot: CLIP
- segment: SAM
- generate: Stable Diffusion

3.14. generate_submission.py
----------------------------
Назначение: Генерация submission.csv.

Форматы:
- label: image,label
- probabilities: image,class1,class2,...

3.15. download_models.py
------------------------
Назначение: Скачивание моделей для offline.

Параметры:
--timm, --yolo, --hf, --all, --check

3.16. app.py
------------
Назначение: Веб-интерфейс.

Вкладки:
1. Инференс (RGB/BGR fix)
2. Анализ данных
3. Разделение данных
4. Обучение (с seed)
5. Hugging Face (кеширование в памяти)

3.17. check_env.py
------------------
Назначение: Проверка окружения.

Smoke test:
- PyTorch forward pass
- Optimizer step
- Save/load checkpoint
- DataLoader
- timm модель
- ONNX Runtime
- YOLO (опционально)

3.18. test_pipeline.sh
----------------------
Назначение: Полный тест.

Последовательность:
check_env → create_data → check_data → find_duplicates → train → predict → submission

================================================================================
4. ОПИСАНИЕ КАЖДОЙ ФУНКЦИИ
================================================================================

4.1. set_seed(seed=42)
----------------------
Файл: train.py
Что делает: Устанавливает seed для воспроизводимости.
Затрагивает: random, numpy, torch, torch.cuda, cudnn.

4.2. get_transforms(image_size, is_train, augmentation_config)
--------------------------------------------------------------
Файл: utils/dataset.py
Что делает: Создает трансформации.
Безопасные: Resize, Normalize.
Конфигурируемые: flip, rotate, crop, brightness, hue, dropout.

4.3. ImageDataset(root_path, transform, class_to_idx)
-----------------------------------------------------
Файл: utils/dataset.py
Что делает: Датасет из папок.
Поддерживает: общий class_to_idx между train/val/test.

4.4. CSVImageDataset(csv_path, transform, class_to_idx)
-------------------------------------------------------
Файл: utils/dataset.py
Что делает: Датасет из CSV.
Колонки: path, label.

4.5. create_dataloaders(...)
----------------------------
Файл: utils/dataset.py
Что делает: Создает DataLoader'ы.
Возвращает: train_loader, val_loader, classes, class_to_idx.

4.6. calculate_metrics(y_true, y_pred, class_names)
---------------------------------------------------
Файл: utils/metrics.py
Что делает: Считает метрики.
Число классов: из class_names (не из y_true).

4.7. stratified_split(...)
--------------------------
Файл: utils/split_data.py
Что делает: Стратифицированное разделение.
Защита: пустые классы, min_val_per_class.

4.8. find_exact_duplicates(data_path)
-------------------------------------
Файл: utils/find_duplicates.py
Что делает: Поиск точных дубликатов по MD5.

4.9. find_near_duplicates(data_path, threshold)
-----------------------------------------------
Файл: utils/find_duplicates.py
Что делает: Поиск почти дубликатов по pHash.

4.10. find_cross_split_leakage(train, val, test)
------------------------------------------------
Файл: utils/find_duplicates.py
Что делает: Поиск утечек между выборками.

4.11. save_checkpoint(...)
--------------------------
Файл: train.py
Что делает: Сохраняет чекпоинт с полной информацией:
- model_state_dict, optimizer_state_dict
- class_names, config
- image_size, mean, std
- timestamp

4.12. log_experiment(...)
-------------------------
Файл: train.py
Что делает: Сохраняет JSON журнал:
- experiment_name, model, seed
- config, metrics_history, best_val_acc

4.13. predict_with_tta(...)
---------------------------
Файл: tta_predict.py
Что делает: TTA предсказание с усреднением.

4.14. test_equivalence(...)
---------------------------
Файл: export_onnx.py
Что делает: Сравнение PyTorch vs ONNX выводов.

4.15. compare_speed(...)
------------------------
Файл: export_onnx.py
Что делает: Замер скорости PyTorch vs ONNX.

5. БЫСТРЫЙ СТАРТ
================================================================================

Шаг 1: Установка (2 мин)
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

Шаг 2: Проверка (1 мин)
python check_env.py

Шаг 3: Offline модели (опционально, 5-10 мин)
python download_models.py --all

Шаг 4: Данные (2 мин)
python utils/split_data.py --source data/all_data --seed 42
python utils/check_data.py --path data/train
python utils/find_duplicates.py --data data/train --exact

Шаг 5: Обучение (1 мин fast / 30+ мин full)
python train.py --fast --seed 42
python train.py --model resnet18 --epochs 50 --seed 42 --exp_name baseline

Шаг 6: Инференс (30 сек)
python predict.py --checkpoint checkpoints/best_model.pth --image test.jpg

Шаг 7: Submission (30 сек)
python generate_submission.py --checkpoint checkpoints/best_model.pth --test_folder data/test

Шаг 8: Полный тест (5 мин)
bash test_pipeline.sh

7. РЕШЕНИЕ ПРОБЛЕМ
================================================================================

CUDA out of memory:
- --batch_size 8
- --image_size 128
- --model resnet18

Медленное обучение:
- mixed_precision: true
- num_workers: 8
- Уменьшить image_size

Overfitting:
- Включить аугментации в config
- weight_decay: 0.001
- early_stopping: 5

Underfitting:
- Больше epochs
- Меньше lr
- Сложнее модель

Порт занят:
- lsof -ti:7860 | xargs kill -9

HF не грузится:
- python download_models.py --hf
- export HF_ENDPOINT=https://hf-mirror.com

ONNX не конвертируется:
- Проверить версию PyTorch
- opset_version=11

Дубликаты в данных:
- python utils/find_duplicates.py --data data/all_data --exact --near
