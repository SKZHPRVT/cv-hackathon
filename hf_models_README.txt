================================================================================
                    HUGGING FACE МОДЕЛИ ДЛЯ CV
================================================================================

НАЗНАЧЕНИЕ
==========
Поддержка Hugging Face моделей для различных CV-задач.
Дополняет основной тулкит современными моделями.

ЗАДАЧИ КОТОРЫЕ РЕШАЕТ
======================
- Классификация (ViT, Swin, ConvNeXT)
- Zero-shot классификация (CLIP)
- Сегментация (SAM, DETR)
- Генерация изображений (Stable Diffusion)
- Загрузка датасетов (datasets)
- Проверка окружения

================================================================================
УСТАНОВКА
================================================================================

pip install transformers datasets diffusers accelerate safetensors

Для GPU (опционально):
pip install accelerate

================================================================================
1. ПРОВЕРКА УСТАНОВКИ
================================================================================

Команда:
python hf_models.py --mode check

Проверяет:
- transformers
- datasets
- accelerate
- safetensors

================================================================================
2. СПИСОК МОДЕЛЕЙ
================================================================================

Команда:
python hf_models.py --mode list

Покажет:
- Модели классификации
- CLIP модели
- Модели сегментации
- Модели генерации
- Популярные датасеты

================================================================================
3. ДАТАСЕТЫ
================================================================================

Команда:
python hf_models.py --mode dataset --dataset cifar10

Популярные датасеты:
- cifar10
- mnist
- fashion_mnist
- imagenet-1k

Что показывает:
- Размер датасета
- Колонки
- Пример записи

================================================================================
4. КЛАССИФИКАЦИЯ
================================================================================

Команда:
python hf_models.py --mode classify --image test.jpg --model google/vit-base-patch16-224

Популярные модели:
- google/vit-base-patch16-224 (Vision Transformer)
- microsoft/swin-tiny-patch4-window7-224 (Swin Transformer)
- facebook/convnext-tiny-224 (ConvNeXT)
- microsoft/resnet-50 (ResNet)

================================================================================
5. ZERO-SHOT КЛАССИФИКАЦИЯ (CLIP)
================================================================================

Команда:
python hf_models.py --mode zero_shot --image test.jpg --labels cat dog car person

Что такое zero-shot:
- Не требует обучения
- Классифицирует по текстовому описанию
- Может распознавать новые классы

Примеры:
python hf_models.py --mode zero_shot --image test.jpg --labels "a photo of cat" "a photo of dog"
python hf_models.py --mode zero_shot --image test.jpg --labels "defect" "normal"

================================================================================
6. СЕГМЕНТАЦИЯ (SAM)
================================================================================

Команда:
python hf_models.py --mode segment --image test.jpg --model facebook/sam-vit-base

Модели:
- facebook/sam-vit-base (быстрая)
- facebook/sam-vit-large (точная)
- facebook/detr-resnet-50 (детекция + сегментация)

================================================================================
7. ГЕНЕРАЦИЯ (Stable Diffusion)
================================================================================

Команда:
python hf_models.py --mode generate --prompt "a cat sitting on a table" --output cat.png

Примеры промптов:
- "a defect on metal surface"
- "synthetic image of a car"
- "medical scan of a brain"

Использование:
- Генерация дополнительных данных
- Создание примеров для презентации
- Аугментация датасета

================================================================================
ПРАКТИЧЕСКИЕ СЦЕНАРИИ
================================================================================

Сценарий 1: Нет данных для обучения
------------------------------------
Используйте zero-shot (CLIP):
python hf_models.py --mode zero_shot --image test.jpg --labels "class1" "class2"

Сценарий 2: Нужна сегментация
-------------------------------
Используйте SAM:
python hf_models.py --mode segment --image test.jpg

Сценарий 3: Мало данных
-------------------------
Используйте генерацию:
python hf_models.py --mode generate --prompt "synthetic data for training"

Сценарий 4: Нужна точная классификация
----------------------------------------
Используйте ViT или Swin:
python hf_models.py --mode classify --image test.jpg --model microsoft/swin-tiny-patch4-window7-224

Сценарий 5: Проверить окружение
---------------------------------
python hf_models.py --mode check

Сценарий 6: Изучить датасет
----------------------------
python hf_models.py --mode dataset --dataset cifar10

================================================================================
РЕШЕНИЕ ПРОБЛЕМ
================================================================================

Проблема: Out of memory
Решение:
- Используйте меньшие модели
- Установите torch.float16
- Используйте CPU

Проблема: Долгая загрузка модели
Решение:
- Скачайте модель заранее
- Сохраните в локальную папку
- Используйте меньшие модели

Проблема: Нет интернета на хакатоне
Решение:
- Скачайте модели заранее
- Сохраните в папку models/
- Укажите локальный путь

СОВЕТЫ
================================================================================

1. Скачайте модели заранее
2. Используйте GPU если есть

4. Для сегментации SAM - лучший выбор

6. Проверяйте окружение через --mode check
