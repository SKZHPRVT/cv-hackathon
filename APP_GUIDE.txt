================================================================================
                    РУКОВОДСТВО ПО ВЕБ-ИНТЕРФЕЙСУ (app.py)
================================================================================

ЗАПУСК
======
python app.py
# Открыть http://localhost:7860

================================================================================
ВКЛАДКА 1: ИНФЕРЕНС
================================================================================

НАЗНАЧЕНИЕ: Предсказание класса изображения обученной моделью.

БЛОК 1: ОДИНОЧНОЕ ПРЕДСКАЗАНИЕ
-------------------------------
Поля:
- "Загрузите изображение" - drag & drop или клик для выбора фото
- "Путь к чекпоинту" - путь к файлу модели (checkpoints/best_model.pth)
- "Топ-K" - сколько предсказаний показать (1-5)

Кнопка: "🎯 Предсказать"

Результат:
- "Результат" - текст с предсказаниями
- "Вероятности" - график с вероятностями классов

Как использовать:
1. Загрузите изображение
2. Укажите путь к модели (по умолчанию checkpoints/best_model.pth)
3. Выберите Top-K
4. Нажмите "Предсказать"
5. Смотрите результат

БЛОК 2: БАТЧ-ПРЕДСКАЗАНИЕ
--------------------------
Поле:
- "Путь к папке" - папка с изображениями для обработки

Кнопка: "📁 Обработать папку"

Результат:
- Таблица с именем файла, предсказанным классом и уверенностью

Как использовать:
1. Укажите путь к папке с изображениями
2. Нажмите "Обработать папку"
3. Получите таблицу с результатами

================================================================================
ВКЛАДКА 2: АНАЛИЗ ДАННЫХ
================================================================================

НАЗНАЧЕНИЕ: Проверка датасета и визуализация аугментаций.

БЛОК 1: АНАЛИЗ ДАТАСЕТА
------------------------
Поле:
- "Путь к данным" - путь к папке с данными (data/train)

Кнопка: "📈 Анализировать"

Результат:
- "Результаты" - статистика (количество, баланс, размеры)
- "Распределение классов" - график

Что показывает:
- Количество изображений в каждом классе
- Баланс классов
- Средние размеры изображений
- Битые файлы
- Форматы файлов

БЛОК 2: АУГМЕНТАЦИИ
--------------------
Поле:
- "Исходное изображение" - загрузка фото

Кнопка: "🎨 Показать"

Результат:
- 5 примеров аугментированных изображений

Что показывает:
- HorizontalFlip
- RandomRotate90
- ShiftScaleRotate
- RandomBrightnessContrast
- HueSaturationValue
- CoarseDropout

================================================================================
ВКЛАДКА 3: РАЗДЕЛЕНИЕ ДАННЫХ
================================================================================

НАЗНАЧЕНИЕ: Разделение датасета на train/val/test.

ПОЛЯ:
- "Путь к данным" - исходная папка со всеми данными
- "Train" - доля тренировочных данных (0.5-0.95)
- "Val" - доля валидационных данных (0.05-0.3)
- "Test" - доля тестовых данных (0.05-0.3)

Кнопка: "🔀 Разделить"

Результат:
- Отчет о разделении

Как использовать:
1. Укажите путь к данным (например: data/all_data)
2. Настройте пропорции (по умолчанию 0.8/0.1/0.1)
3. Нажмите "Разделить"
4. Данные будут скопированы в data/train, data/val, data/test

ВАЖНО: Сумма пропорций должна быть 1.0

================================================================================
ВКЛАДКА 4: ОБУЧЕНИЕ
================================================================================

НАЗНАЧЕНИЕ: Запуск обучения модели из браузера.

ПОЛЯ:
- "Конфиг" - путь к config.yaml (по умолчанию configs/config.yaml)
- "Эпохи" - количество эпох (пусто = из конфига)
- "Модель" - выбор модели из списка
- "Fast mode" - галочка для быстрого теста

Кнопка: "🚀 Обучить"

Модели на выбор:
- resnet18 (быстрая)
- resnet34
- resnet50 (точная)
- efficientnet_b0 (эффективная)
- efficientnet_b3 (точная)
- mobilenetv3_large_100 (мобильная)

Результат:
- "Лог" - вывод обучения в реальном времени

Как использовать:
1. Убедитесь, что данные подготовлены
2. Выберите модель
3. Укажите эпохи (или оставьте пусто)
4. Нажмите "Обучить"
5. Следите за логом

FAST MODE:
- 1 эпоха
- batch_size = 8
- Для быстрой проверки пайплайна

================================================================================
ВКЛАДКА 5: HUGGING FACE
================================================================================

НАЗНАЧЕНИЕ: Современные модели через Hugging Face.

ПОД-ВКЛАДКА 5.1: КЛАССИФИКАЦИЯ
-------------------------------
Поля:
- "Изображение" - загрузка фото
- "Модель" - выбор HF модели

Модели:
- google/vit-base-patch16-224 (Vision Transformer)
- microsoft/swin-tiny-patch4-window7-224 (Swin)
- facebook/convnext-tiny-224 (ConvNeXT)
- microsoft/resnet-50 (ResNet)

Кнопка: "🏷️ Классифицировать"

Результат:
- Топ-5 предсказаний с вероятностями
- График

Когда использовать:
- Нужна точная классификация
- Нет времени на обучение
- Стандартные классы (ImageNet)

ПОД-ВКЛАДКА 5.2: ZERO-SHOT (CLIP)
-----------------------------------
Поля:
- "Изображение" - загрузка фото
- "Метки через запятую" - свои классы (например: cat, dog, car)

Кнопка: "🏷️ Zero-shot"

Результат:
- Вероятности для каждой метки
- График

Когда использовать:
- Нет обучающих данных
- Нужно классифицировать новые классы
- Быстрая проверка гипотез

Примеры меток:
- "defect, normal"
- "cat, dog, bird"
- "day, night"
- "indoor, outdoor"

ПОД-ВКЛАДКА 5.3: СЕГМЕНТАЦИЯ (SAM)
------------------------------------
Поля:
- "Изображение" - загрузка фото

Кнопка: "🧩 Сегментировать"

Результат:
- Маска сегментации
- Статус

Когда использовать:
- Нужно выделить объекты
- Разметка данных
- Анализ изображений

Особенности:
- Работает без обучения
- Находит все объекты
- Может быть медленным на CPU

ПОД-ВКЛАДКА 5.4: ГЕНЕРАЦИЯ (STABLE DIFFUSION)
-----------------------------------------------
Поля:
- "Промпт" - текстовое описание

Кнопка: "🎨 Генерировать"

Результат:
- Сгенерированное изображение
- Статус

Когда использовать:
- Создание синтетических данных
- Аугментация датасета
- Примеры для презентации

Примеры промптов:
- "a defect on metal surface"
- "a cat sitting on a table"
- "medical scan of a brain"
- "synthetic image of a car"

ВНИМАНИЕ: Требует много памяти и времени на CPU

================================================================================
СОВЕТЫ ПО ИСПОЛЬЗОВАНИЮ
================================================================================

1. Скачайте HF модели заранее (требуют интернет при первом запуске)
2. Для быстрого старта используйте Fast mode
3. Батч-обработка экономит время
4. Zero-shot подходит для быстрой проверки
5. SAM полезен для разметки данных
6. Сохраняйте результаты экспериментов

================================================================================
РЕШЕНИЕ ПРОБЛЕМ
================================================================================

ПРОБЛЕМА: Кнопка не реагирует
Решение: Обновите страницу (F5)

ПРОБЛЕМА: Модель не загружается
Решение: Проверьте путь к чекпоинту

ПРОБЛЕМА: HF модель не скачивается
Решение: Проверьте интернет, попробуйте позже

ПРОБЛЕМА: Out of memory
Решение: Используйте меньшую модель

ПРОБЛЕМА: Порт занят
Решение: lsof -ti:7860 | xargs kill -9
